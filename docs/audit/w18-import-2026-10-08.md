# w18 — 확정 소스 blob 재사용과 스냅샷 배치 저장

- 기준 `6ddeefb`, 기존 후보 `h7hpw4` (`4bd54bf`, xpc-required), baseline `tZgvV7`.
- 통합 브랜치 `release/gate-followup-20261008`. 후보 패키지 검증과 성능 판정은 별도이며, 이 문서로 출시 게이트를 통과시키지 않는다.

## 변경과 정확성 경계

- `LocalSnapshotStore`는 같은 프로젝트의 **현재 COMMITTED generation + sealed manifest**에 있는 blob만 재사용 후보로 읽는다. 매번 승인된 원본 파일을 다시 안전하게 읽고 Git OID와 SHA-256·크기를 확인한다. mtime/크기만 같은 파일을 재사용하지 않는다. 삭제·rename은 새 manifest의 정확한 경로 집합으로 반영한다.
- 변경 없는 blob은 소스 원문을 다시 전송·암호화·fsync하지 않는다. backend → private Unix broker의 `RETAIN`은 요청당 1–128개의 정확한 `{sha256,byteSize,keyId}` 주소만 받으며, vault는 기존 암호문을 다시 인증하고 키 일치까지 확인한다. 외부 경로·원문·다른 프로젝트·잘못된 응답 개수는 허용하지 않는다.
- 새 blob은 기존 STAGE/session/sequence/BARRIER 계약을 유지한다. RETAIN도 queued stage를 먼저 내구성 있게 flush한다. 손상된 재사용 blob은 살아 있는 원본으로 조용히 복구하지 않고 발행 전에 실패한다. 모든 승인 digest와 발행 guard, 이전 snapshot 불변성은 유지한다.
- `source_blobs`·`source_manifest_entries`와 파일 inventory는 500개 이하 JDBC batch로 저장한다. 기존 트랜잭션과 manifest 일관성 검사를 보존한다. schema/Flyway 변경 없음.
- 원본 탐색·승인·안전한 staging 복사·Git snapshot materialization은 여전히 전체 입력에 수행한다. 이 변경은 그 보안 경계를 생략하는 파일시스템 캐시가 아니다. 파싱 결과 재사용은 w16/w17에서 별도로 다룬다.

backend 회귀는 `SourceStoreClientTest`, `LocalSnapshotStoreBarrierTest`, `RetainedSourceIntegrationTest`, `ImportSecretsCorpusIntegrationTest`만 실행했다. 실제 PostgreSQL/Redis fixture와 Node 소스 broker를 사용하는 통합 시험은 rename 후 원문 재전송 없음, 동일 크기 변경과 변경 없는 파일의 혼합, 손상 blob의 발행 거부 및 이전 generation 유지, 승인·비밀 제외·race·rollback을 확인한다. 실제 OS Keychain이나 사용자 프로필을 사용하지 않았다. Gradle의 외부 loopback handshake 경고는 원본 로그에 남았으며 시험 실패는 0이다.

첫 `vault-red.log`는 편집 도구 형식 오류로 새 시험이 적용되기 전 실행되어 회귀 증거가 아니다. 실제 RED는 `vault-red-2.log`다. 이것도 삭제하지 않았다.

## 재실행 명령

모든 heavy command 전에 `validation/local/coordination/wait-quiet.sh`를 실행했다. 다음은 calm-meadow 작업트리 루트 기준이다.

```sh
node --test desktop/test/source-vault-batch.test.cjs \
  desktop/test/source-broker.test.cjs desktop/test/source-vault-windows.test.cjs

E="$PWD/validation/local/w18-import/backend-final"
env -i HOME="$HOME" PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin LANG=C LC_ALL=C \
  DOCKER_HOST="unix://$HOME/.docker/run/docker.sock" \
  CI_DOCKER_TEST_ROOT="$E" CI_DOCKER_TEST_TMP="$PWD/.citd-w18final" \
  backend/gradlew -p backend --offline --no-daemon --console=plain --max-workers=2 \
  -I "$PWD/validation/pre-release/docker-integration.init.gradle" cleanTest test \
  --tests dev.codeintelligence.source.SourceStoreClientTest \
  --tests dev.codeintelligence.project.LocalSnapshotStoreBarrierTest \
  --tests dev.codeintelligence.project.RetainedSourceIntegrationTest \
  --tests dev.codeintelligence.project.ImportSecretsCorpusIntegrationTest
```

각 재실행은 새 증거 디렉터리와 새 `.citd-*` 디렉터리를 준비해야 한다. 기존 결과를 덮어쓰지 않는다. 합성 wrapping fixture만 사용한 별도 smoke의 임시 스크립트·임시 vault는 종료 후 제거하고 결과 로그를 남겼다.
