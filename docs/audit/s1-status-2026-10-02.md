- 구현 후 검증 중: snapshot 선택·file API·React Query/Monaco model key 분리, legacy unknown/근거 provenance 표시, 명시적 현재 소스 열기, feature evidence context, 기존 note 링크 보존, local refresh 완료 후 cache 무효화.
