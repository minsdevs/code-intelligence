## 실행 명령

cwd는 할당 작업트리. 실행마다 공통 `wait-quiet.sh`를 먼저 호출했다.

```sh
CI_DOCKER_TEST_ROOT="$PWD/validation/local/w20-java-perf/profile2" \
CI_DOCKER_TEST_TMP="$PWD/.citd-w20profile" \
DOCKER_HOST="unix://$HOME/.docker/run/docker.sock" caffeinate -i \
backend/gradlew -p backend --offline \
  -I "$PWD/validation/pre-release/docker-integration.init.gradle" \
  -I "$PWD/validation/local/w20-java-perf/profile.gradle" \
  cleanTest test --tests dev.codeintelligence.analysis.java.JavaPipelineProfileTest
```

명령/준비 실패 설명은 `validation/local/w20-java-perf/commands.txt`에도 보존한다. 이후 DB/JFR 실행은 native lock 안에서 QUIET-REQUIRED를 독점 소유하고 trap으로 정리하며 load1<4에서 시작한다.
