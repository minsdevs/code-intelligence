# 기획 평가 루브릭 v1.0 — 집필 전 고정

고정일: 2026-10-02. 이 문서는 PRD·설계 본문 집필 전에 생성했다. 평가 대상은 **구현 가능한 기획의 품질**이며 현재 제품의 출시 준비도와 구분한다. 원문 요구의 배점·95점 기준을 변경하지 않는다. 이후 수정은 새 버전과 변경 이유로만 가능하며 이미 받은 점수를 소급해 유리하게 재산정하지 않는다.

## 채점·통과 규칙

- 세부항목별 정수 또는 0.5점 단위. 만점은 결정을 구현·검증할 수 있고 구체적인 반례를 처리할 때만 준다. 기능이 코드에 있거나 테스트 숫자가 크다는 이유로 가산하지 않는다.
- 모든 영역에 점수, 문서 위치/근거, 남은 결함, 수정 전후를 기록한다. 누락은 0, 결정·검증 계획이 약하면 부분점. 근거 없는 자신감은 점수가 아니다.
- **95/100 이상 AND 중대한 미결정 0 AND 독립 검토의 미해결 Critical/High 0**이어야 기획 통과다. 중대한 보안·분석 정확도·아키텍처 선택이 남으면 점수와 무관하게 HOLD.
- 중대 여부: 데이터/자격증명 노출 또는 손실 경로, 거짓 확정/완전성 표시, 핵심 기능의 상충 설계·미정 계약, 검증 불가능한 핵심 수용기준. 단순 운영 계정 식별·실행 증거 대기는 명확한 안전 기본값/출시 차단이 있으면 구현 착수의 설계 미결정과 구별한다.
- 운영 권한 선택이 설계의 보안 경계를 바꾸면 HOLD. 발급 주체·실기기 검증 등 구현 후 증거는 별도 release No-Go이며 기획 점수로 해제하지 않는다.
- 자체 점검과 별도 리뷰를 구분한다. 독립 리뷰어는 초안 작성자가 아니며, 고정 루브릭과 원문을 읽고 반대 사례를 제시하고 독자 채점한다. 동일 모델 계열 리뷰는 사람/실사용자 검증을 대체하지 않는다.
- 목표 미달이면 결함을 수정하고 같은 루브릭으로 재검토한다. 점수 맞추기·통과 보장·완벽 표현은 금지. 통과하더라도 이 작업에서 제품 구현을 시작하지 않는다.
