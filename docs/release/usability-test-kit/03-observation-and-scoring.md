## 심각도 정의

| 등급 | 정의 | 게이트 영향 |
|---|---|---|
| 중대(Critical) — 추정을 사실로 | 참가자가 후보·추정·미측정·미발견 상태를 확정 사실로 받아들이고, 그 판단을 근거로 결정(“SMS가 반드시 나간다”, “영향 없음”, “환불된다”)을 말함. 자가 수정 없이 과제를 마치면 중대 | 1명이라도 있으면 게이트 FAIL |
| 심각(Severe) — 데이터/권한 | 원본·snapshot·노트가 의도와 다르게 삭제되거나, 소스·토큰이 기기 밖으로 나가거나, 참가자가 의도하지 않은 권한(GitHub·AI 키)을 부여하게 됨 | 1건이라도 있으면 게이트 FAIL |
| 높음(High) | 도움 없이는 과제를 마칠 수 없게 만든 UI 문제 | 과제 미완료로 이어짐 |
| 중간(Medium) | 과제는 마쳤지만 2분 이상 지연 또는 잘못된 경로를 거침 | 기록, 개선 목록 |
| 낮음(Low) | 문구·배치 불편, 지연 2분 미만 | 기록 |

“도움 없이 완료”: 진행자 힌트 0회, 과제 시간 15분 이내(U1은 첫 분석 시간 제외), 완료 조건 충족.
진행자가 앱 오류 때문에 재시작해 준 경우는 도움으로 세지 않되 관찰지와 워크북에 따로 표시합니다.

## 채점 워크북 구조 (`scoring-workbook.csv`)

참가자×과제마다 1행(8명×4과제 = 32행), 이해도 질문은 같은 참가자 행의 열로 둡니다.

| 열 | 값 |
|---|---|
| participant | P1–P8 |
| level | beginner / intermediate / senior |
| background | java / web / python |
| task | U1–U4 |
| completed_unaided | yes / no |
| hints | 정수 |
| task_minutes_excl_first_analysis | 소수 1자리 |
| within_15_min | yes / no |
| screen_to_evidence_seconds | 정수 또는 빈칸(해당 없음) |
| critical_inference_error | yes / no (이 과제에서 발생) |
| severe_data_permission_error | yes / no |
| probe_ids_wrong | 예: `Q4;Q5` |
| app_restart_by_moderator | yes / no |
| notes | 짧은 메모 |

집계(시트 하단 또는 별도 시트):

| 지표 | 계산 | 기준 |
|---|---|---|
| U1–U4 전부 도움 없이 완료한 참가자 수 | participant별 U1–U4 4행이 모두 `completed_unaided=yes`이고 `within_15_min=yes` | ≥ 7 / 8 |
| 중대 “추정을 사실로” 오류 참가자 수 | `critical_inference_error=yes`가 한 행이라도 있는 participant 수 | = 0 |
| 심각 데이터/권한 오류 건수 | `severe_data_permission_error=yes` 행 수 | = 0 |
| 화면→근거 시간 중앙값 | `screen_to_evidence_seconds`가 있는 모든 행의 중앙값 | ≤ 60 초 |
| 모집 구성 | level별 participant 수, background 종류 | 각 level ≥ 2, background 혼합 |

## 재시험 규칙

1. 기준 하나라도 미달이면 해당 실패의 원인을 관찰지에서 찾아 UI(문구·흐름)를 고치고 회귀 테스트를 추가합니다.
2. 재시험은 **새 과제**로 합니다. 같은 문장·같은 프로젝트를 다시 쓰지 않고 `library-loans` fixture로 같은 구조의 과제(U1–U4 대응)를 새로 씁니다.
   예: U3 → “대출 목록 화면에서 반납 버튼이 서버의 어떤 코드로 이어지는지”, U4 → “`LoansService`의 반납 처리 변경의 영향”.
3. 재시험 참가자는 이전 세션 참가자가 아닌 새 8명(같은 모집 매트릭스)입니다.
4. 이전 결과는 지우지 않고 워크북에 `round` 열을 추가해 나란히 보관합니다.
5. 재시험에서도 기준을 다시 전부 적용합니다(부분 재시험으로 통과 처리하지 않음).
