## 스크리너 (전화·메신저 5분)

1. 지금 업무에서 가장 많이 쓰는 언어는 무엇인가요? (Java/Kotlin · JavaScript/TypeScript · Python · 기타)
2. 개발 실무 경력은 몇 년인가요?
3. 처음 보는 프로젝트에서 “이 버튼을 누르면 서버에서 무슨 일이 일어나는지” 직접 따라가 본 적이 있나요? 최근 언제였나요?
4. 코드 검색/분석 도구(IDE 검색 외)를 써 본 적이 있나요? 어떤 것인가요?
5. Mac을 업무에 매일 쓰나요?
6. 화면 낭독기·확대 등 보조기술을 쓰나요? (예/아니오, 쓰는 경우 종류) — 사용자는 별도 칸에 기록하고 제외하지 않습니다.
7. 이 제품(Code Intelligence) 개발이나 이전 시험에 참여한 적이 있나요? → 예이면 제외.
8. 60분 세션 녹화(화면+음성)에 동의할 수 있나요? → 아니오이면 관찰지 수기 기록만으로 진행 가능 여부를 확인.

## 데이터 취급 (진행자 체크리스트)

- ☐ 세션 Mac은 시험 전용 macOS 사용자 계정(새 프로필)으로 로그인했다. 개인 계정·회사 계정 프로필을 쓰지 않는다.
- ☐ 앱 설정에서 AI가 꺼져 있고 provider 키가 없다. 참가자에게 키 입력을 요청하지 않는다.
- ☐ GitHub에 로그인하지 않는다. 참가자의 GitHub 계정으로 로그인하게 하지 않는다.
- ☐ 분석 대상은 `02`에서 만든 합성 프로젝트뿐이다. 참가자 소스·회사 소스는 기기에 복사하지 않는다(이 기기 밖으로 소스가 나가지 않는다).
- ☐ 녹화본은 암호화된 저장소에만 두고, 파일명에 참가자 ID만 쓴다.
- ☐ 세션 후 시험 계정의 앱 데이터는 다음 참가자 전에 새 macOS 사용자 계정으로 교체한다(이전 참가자의 노트·흔적이 남지 않게).
